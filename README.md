# Co-t-trajet
Calculez combien de carburant et d’argent coûte votre trajet en voiture. Choisissez votre véhicule, votre carburant (essence, diesel, GPL, électrique) et votre pays : le site affiche la consommation, le coût du trajet, par km et par personne, les dépenses mensuelles et annuelles, et le CO₂ émis. Gratuit, sans inscription.
